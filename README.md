# フォルダ構成について

**Dataフォルダ**
- ゲームで使っている JSONファイルです。


**Scriptsフォルダ**
- Core : ゲームを進行、およびゲームルールを定義するためのスクリプトです。
    - Combat : 戦闘関係の規則を定義したスクリプトです。(ダメージ、状態異常)
    - GameFlow 
        - AdventureMode : 基本ゲームモード進行用スクリプトです。(ステージクリアモード)
        - ChallengeMode : 倒すまで戦う無限モード進行用スクリプトです。
        - Presentation : BGM、カメラ、フェードイン・フェードアウトなどの見せるための要素を制御するスクリプトです。
        - Systems : キャラクターの寿命管理、衝突判定、マップ構成などを担当するスクリプトです。
    - Pooling : オブジェクトプール関係スクリプトです。
    - Utility : 距離計算、衝突計算用スクリプトをまとめました。
- Data : ScriptableObjectやJSONなどの外部ファイルでデータを作成するためのスクリプトです。
    - DataBase : ScriptableObject作成用スクリプトです。
    - Loaders : JSONからデータを読み込み、ゲームで使うためのスクリプトです。
    - Models : ステージやキャラクターステータスデータなどのJSON作成用スクリプトです。
- Entities : キャラクター、弾、アイテムなどのゲームに登場するエンティティ関連スクリプトです。
    - AbilityCards : レベルアップで獲得するアイテムです。
    - Character : キャラクタースクリプトです。
    - DropItems : 特殊能力獲得などのイベントを発生するアイテムです。
    - Effect : エフェクト制御用スクリプトです。
    - Map : 特殊マップタイルなどを作成するためのスクリプトです。
    - Projectiles : 弾のスクリプトです。
- TitleScene : タイトルシーン専用スクリプトです。
- WorldMap : ゲームモード選択シーン専用スクリプトです。
